# 도형 지우기 작업 도구

이 폴더는 지우개를 집어 보드 위 도형을 지우는 작업에만 적용되는 도구를 모읍니다.
목표 도형, 보드 위치, 잉크 잔량, 사람 개입(HIL), 성공·실패 판정 같은 task 전용
개념을 사용합니다.

- `analysis/`: 학습 장면과 실제 보드 배치의 차이를 분석·시각화합니다.
- `runtime/`: 종료 게이트와 HIL 개입을 포함한 실제 실행을 담당합니다.
- `evaluation/`: 잉크 측정, 성공 판정, 평가 세션과 통계를 담당합니다.
- `dataset/`: frame 범위, 라벨, 학습 데이터셋 생성을 담당합니다.
- `qc/`: 녹화 프레임 범위와 품질 검토를 담당합니다.
- `augmentation/`: Top View 영상에 다른 도형의 방해 PNG를 안전 영역에 합성해
  학습용 증강 영상을 만드는 독립 패키지입니다.
- `lib/`: 이 task 안에서 분석·평가 도구가 함께 쓰는 보조 모듈을 둡니다.
