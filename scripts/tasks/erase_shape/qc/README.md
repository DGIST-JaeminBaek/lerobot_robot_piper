# 도형 지우기 녹화 QC 도구

이 폴더에는 도형 지우기 시연 녹화의 시작·종료 프레임, 그리퍼 해제, 장면 전환을
검토하고 학습용 컷 범위를 관리하는 도구를 둡니다.

- `qc_core.py`: UI와 배치 도구가 공유하는 단일 녹화 판정 로직입니다.
- `qc_studio.py`: 녹화 목록·프레임·판정을 보며 사람이 컷 범위를 검토하는 GUI입니다.
- `qc_recompute_all.py`: 세션 전체 QC 결과를 다시 계산합니다.
- `qc_extract_review_frames.py`, `qc_review_web.py`: 대량 녹화의 사람 리뷰용 프레임·웹 화면을 만듭니다.
- `review_cuts.py`: 자동 컷과 매니페스트 컷의 차이를 이미지로 검토합니다.
- `qc_extend_flagged_release_view.py`: 표시된 그리퍼 해제 구간을 추가 점검하는 일회성 보조 도구입니다.

프레임 경계 탐지·매니페스트 생성의 공통 규칙은 인접한 `../dataset/` 도구를 사용합니다.
