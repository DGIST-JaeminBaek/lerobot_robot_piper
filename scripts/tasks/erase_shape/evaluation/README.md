# 도형 지우기 평가 도구

이 폴더에는 보드의 잉크 잔량과 목표 도형을 기준으로 도형 지우기 task의 성공을
판정·검토·집계하는 도구를 둡니다.

- `erase_check.py`: 실행 중 park 상태에서 종료 가능한지 판단하는 실시간 게이트입니다.
- `erase_eval.py`: 저장된 실행 결과를 오프라인으로 채점합니다.
- `erase_eval_ui.py`: 실행 → 자동 채점 → 사람 확인을 반복하는 평가 세션 UI입니다.
- `erase_stats.py`: 조건별 실행 JSON을 읽어 성공률·통계를 집계합니다.
- `reach_eval_ui.py`: **어느 도형으로 갔는지만** 보는 축소판 세션 UI입니다. 영상을
  안 남기고(러너 `--mode demo`) 완주 여부도 안 봅니다. 방해 도형을 넣은 뒤 "프롬프트
  대로 옳은 도형을 골랐나"를 지우기 실력과 분리해서 재려고 만들었습니다. 판정은
  사람이 하고, 잉크 변화 기반 추천을 미리 골라줍니다. 실행은 `scripts/14__reach_session.sh`.
- `eval_kit/`: 합성·저장 판정 프레임 기반의 독립 채점, 라벨 보정, 결과 요약 도구입니다.

이 폴더의 기준은 목표 도형·보드·잉크라는 task 전용 가정을 포함하므로 범용
Piper 검증 도구에는 두지 않습니다.

보드·잉크·가림을 분석하는 공통 영상 측정 로직은 `../lib/ink_metric.py`에 둡니다.
